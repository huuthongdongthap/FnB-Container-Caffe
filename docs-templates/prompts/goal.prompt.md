# Goal Definition Prompt

**Purpose:** Define project goals, objectives, and success criteria.

**Context:**
You are helping define the goals for {PROJECT_NAME}, a {BUSINESS_DOMAIN} system.

**Instructions:**

1. **Vision Statement** - Create an inspiring 1-2 sentence vision that describes the desired future state.

2. **Mission** - Define the project's purpose: who we serve, what we deliver, why it matters.

3. **Core Objectives** - List 3-5 SMART objectives:
   - Specific
   - Measurable
   - Achievable
   - Relevant
   - Time-bound

4. **Success Metrics** - Define 3-5 key metrics with targets:
   - Metric name
   - Definition (how calculated)
   - Target value
   - Current baseline (if applicable)

5. **Scope Boundaries** - Clearly define:
   - What's IN scope
   - What's OUT of scope
   - Known constraints (budget, timeline, resources)

6. **Stakeholders** - Identify all key stakeholders with their roles.

**Output Format:**

```markdown
# Project Goal Definition

## Vision
{Vision statement}

## Mission
{Mission statement}

## Objectives
1. {Objective 1}
2. {Objective 2}
...

## Success Metrics
| Metric | Target | Current | Measurement |
|--------|--------|---------|-------------|
| {Metric 1} | {Target 1} | {Current 1} | {Method 1} |
| ...

## Scope
### In Scope
- {In-scope item 1}
- ...

### Out of Scope
- {Out-of-scope item 1}
- ...

## Constraints
- {Constraint 1}
- ...

## Stakeholders
| Role | Responsibility |
|-----|----------------|
| {Role 1} | {Responsibility 1} |
| ...
```

**Additional Notes:**
- Keep the goal document concise (1-2 pages max)
- Use clear, unambiguous language
- Make goals actionable and measurable
- Align with organizational strategy
