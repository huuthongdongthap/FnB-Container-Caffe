## 3. Common Issues / Cac Van De Thuong Gap

### Login / Dang Nhap

**Q: Khong the dang nhap? (Can't login?)**
A: Kiem tra email va mat khau. Neu quen mat khau, bam "Quen mat khau" de dat lai. (Check email and password. If forgot password, click "Forgot password" to reset.)

### Orders / Don Hang

**Q: Khong thay don hang? (Can't see orders?)**
A: Kiem tra bo loc (filters) -- xem thu dang chon "All orders" hay chi "Today". Lam moi trang (refresh page) neu can. (Check filters -- see if "All orders" or only "Today" is selected. Refresh the page if needed.)

### Payment / Thanh Toan

**Q: Thanh toan PayOS loi? (PayOS error?)**
A: Kiem tra cau hinh API key -- vao Settings > Payment > PayOS va xac nhan cac thong tin con dung. Neu van loi, lien he ho tro Tier 2. (Check API key configuration -- go to Settings > Payment > PayOS and verify credentials are correct. If still failing, contact Tier 2 support.)

### Menu / Thuc Don

**Q: Menu khong hien thi? (Menu not showing?)**
A: Kiem tra trang thai san pham -- vao Products, dam bao san pham da duoc bat la "Available". Kiem tra danh muc co duoc kich hoat khong. (Check product status -- go to Products, make sure product is set to "Available". Check that the category is active.)

### QR Code

**Q: QR code khong quet duoc? (QR code not scanning?)**
A: In lai QR code tu dashboard > QR Codes. Dam bao hinh anh con ro rang, khong bi nhoe hoac bi che. (Re-print the QR code from Dashboard > QR Codes. Make sure the image is clear, not smudged or covered.)

## 4. Escalation / Chuyen Tiep

```
Tier 1: Chat/Zalo Support (AI-assisted)
  --> Reply to common questions, send FAQ
  --> Use troubleshooting scripts

Tier 2: Technical Support (Operator)
  --> Investigate account-level issues
  --> Modify configurations, check logs
  --> Escalate to Tier 3 if root cause is code / infrastructure

Tier 3: Development Team
  --> Bug fixes, new features
  --> Infrastructure issues
  --> Scheduled for next release cycle
```

**Escalation triggers / Dieu kien chuyen tiep:**
- Tier 1 cannot resolve within SLA time
- Issue requires changing code or database
- Issue repeats across multiple clients (systemic)
- Security or data loss concern
