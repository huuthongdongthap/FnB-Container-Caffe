# BEHAVIOR GRAPH — USER JOURNEYS

## Overview

This document maps key customer personas through their interactions with AURA Cafe, identifying touchpoints, emotional states, and opportunity areas for improvement.

---

## Persona 1: Dine-in Customer "Minh"

**Demographics:** 25-35 years old, professional, works remotely  
**Goal:** Enjoy coffee and food in a comfortable, aesthetic space

### Journey Map

| Stage | Touchpoint | Action | Emotion | Pain Points | Opportunity |
|-------|------------|--------|---------|-------------|-------------|
| **Discovery** | Instagram, friend referral | Sees cafe photos, reads reviews | Curious, hopeful | Unclear if space is suitable for working | Show workspace amenities (power, WiFi speed) in ads |
| **Pre-arrival** | Website menu | Browses drinks, prices | Informed | No real-time table availability | Show current occupancy (green/yellow/red) |
| **Arrival** | Front door, reception | Greeted, seated | Welcomed | Wait time if no table | Queue management system, waitlist SMS |
| **Ordering** | POS or self-order QR | Selects items, asks questions | Decisive but wants recommendations | Menu too large, unsure what to order | "Barista's choice" recommendation widget |
| **Waiting** | Table | Works on laptop, orders arrive | Anticipation | Long wait without updates | SMS notification "Your order is ready" |
| **Service** | Table | Eats, drinks, uses WiFi | Satisfied | Slow Wi-Fi, noisy environment | Ensure 50 Mbps minimum, sound zoning |
| **Checkout** | POS | Pays, receives receipt | Relief | Forgetting loyalty card | Ask phone number instead of card |
| **Post-visit** | SMS/email | Receipt, loyalty points added | Happy | No follow-up | Thank you message, invite to join community |
| **Return** | App/website | Checks points, redeems reward | Loyal | Hard to remember rewards | Push notification when points near redemption |

## Persona 2: Online Orderer "Lan"

**Demographics:** 28 years old, office worker, orders lunch  
**Goal:** Quick delivery of coffee/snack to office

### Journey Map

| Stage | Touchpoint | Action | Emotion | Pain Points | Opportunity |
|-------|------------|--------|---------|-------------|-------------|
| **Discovery** | Colleague recommendation | Hears about cafe delivery | Trusting | Unclear delivery area | Interactive delivery map on website |
| **Browse** | Menu page | Views items, filters by availability | Decisive | Out-of-stock items not marked clearly | Real-time stock indicators |
| **Cart** | Cart page | Adds items, enters promo code | Focused | Promo code rejected without reason | Show why code invalid (expired, min not met) |
| **Checkout** | Checkout form | Enters address, phone, payment | Nervous (first order) | Address validation unclear | Map preview of delivery location |
| **Payment** | PayOS QR | Scans, pays via bank app | Anxious | QR timeout, payment fails | Retry button without losing cart |
| **Tracking** | Track order page | Watches status updates | Eager | No ETA displayed | Show estimated delivery time countdown |
| **Delivery** | Handoff with rider | Receives order | Relief | Rider late, no notification | Real-time rider location on map |
| **Post-delivery** | Email/SMS | Receipt, feedback request | Satisfied (if good) | Too many feedback prompts | Single-tap rating, optional detailed review |

## Persona 3: Reservation Booker "Huy"

**Demographics:** 35, business owner, planning team meeting  
**Goal:** Book table for 6 people, confident the space will meet needs

### Journey Map

| Stage | Touchpoint | Action | Emotion | Pain Points | Opportunity |
|-------|------------|--------|---------|-------------|-------------|
| **Research** | Website reservation page | Checks table sizes, availability | Planning | Cannot see table layout | Interactive floor plan with table capacities |
| **Booking** | Form | Selects date, time, guests, notes | Cautious | No confirmation until after submit | Calendar integration to see conflicts |
| **Confirmation** | Email/SMS | Receives booking details | Reassured | No reminder before event | Auto-reminder 24h before, 2h before |
| **Pre-arrival** | SMS | Gets directions, parking info | Prepared | Forgetting booking details | Include QR code for quick check-in |
| **Arrival** | Host stand | Announces reservation, greeted | Confident | Wait despite reservation | Host app to see reservations in real-time |
| **During** | Table | Meeting, orders, networking | Productive | Time pressure (next booking) | Clear communication of reservation end time |
| **Departure** | Checkout | Pays, receives receipt | Satisfied | Split bill complicated | Pre-split bill option during booking |
| **Post-visit** | Email | Feedback request, loyalty points | Valued | Generic feedback form | Reference specific items ordered in feedback |

## Persona 4: Event Attendee "An"

**Demographics:** 22, student, attends coding workshop  
**Goal:** Learn something new, meet community, have fun

### Journey Map

| Stage | Touchpoint | Action | Emotion | Pain Points | Opportunity |
|-------|------------|--------|---------|-------------|-------------|
| **Discovery** | Facebook event, Meetup.com | Finds event, registers | Excited | Event description unclear | Detailed agenda, speaker bios |
| **Ticket purchase** | pretix/Cal.com | Buys ticket, receives QR | Trusting (payment) | Multiple platforms confusing | Single-brand ticketing flow |
| **Pre-event** | Email | Receives ticket, agenda, location | Anticipation | Forgets to add to calendar | One-click calendar add (.ics attachment) |
| **Arrival** | Cafe entrance | Shows QR, checks in | Nervous (first time) | Confusing signage | Clear "Event Entrance" signs, staff greeting |
| **Check-in** | Staff scans QR | Gets name tag, welcome | Welcomed | Long line, slow scanning | Self-check-in kiosks |
| **During event** | Seating, WiFi, coffee | Networking, listening | Engaged | Poor WiFi, no power outlets | Dedicated event WiFi network, power strips |
| **Networking** | Break time | Socializes, gets coffee | Social | No way to connect with others | Event app with attendee directory (opt-in) |
| **Post-event** | Email | Resources, follow-up survey | Grateful | Survey too long | Micro-surveys: 3 questions max |
| **Follow-up** | LinkedIn/FB group | Joins community, shares experience | Connected | No way to stay in touch | Auto-invite to community group |

## Persona 5: Loyalty Member "Trang"

**Demographics:** 40, regular customer, family visits weekly  
**Goal:** Maximize rewards, feel recognized, save money

### Journey Map

| Stage | Touchpoint | Action | Emotion | Pain Points | Opportunity |
|-------|------------|--------|---------|-------------|-------------|
| **Signup** | Receipt QR, checkout page | Registers with phone | Willing | Long form, unclear benefits | One-tap signup via OTP |
| **Onboarding** | Welcome email | Learns about tiers, cashback | Curious | Info overload | Progressive onboarding: learn as you earn |
| **Earning** | Every purchase | Pays, sees points add | Satisfied | Don't know current balance | Balance visible on receipt, app |
| **Tier progress** | Profile page | Checks progress to next tier | Motivated | Progress bar not clear | Visual progress bar with next tier benefits |
| **Redemption** | Checkout | Applies cashback/voucher | Thrilled | Limited to 50% per order | Higher limit for Platinum tier |
| **Birthday** | Birthday week | Receives discount | Special | Forgets to use | Auto-apply at checkout |
| **Referral** | Share code | Sends to friends, gets bonus | Generous | Friend doesn't use code | Reminder when friend first visits |
| **Expiry** | Email | Gets notified points expiring | Urgent | Not sure what to do | Suggestion: "Use points on X item" |
| **VIP treatment** | In-store | Recognized by staff, special perks | Valued | Not consistently recognized | Staff app showing customer tier & preferences |

## Integration Touchpoints

### System-Wide Flows

| Flow | Steps | Systems Involved |
|------|-------|------------------|
| **Order → Payment → Loyalty** | Order created → Payment confirmed → Points/cashback credited → Tier updated | orders.js, payment.js, webhooks.js, loyalty.js |
| **Reservation → Arrival → Check-in** | Book → Reminder SMS → Arrive → Staff check-in → Loyalty points | reservations.js, checkin.js, loyalty.js |
| **Referral Loop** | A refers B → B signs up → A gets bonus → B makes purchase → A gets tier boost | referrals.js, loyalty.js, orders.js |
| **Cron Operations** | Every 5min: check overdue orders, expire points, churn detection | cron.js |

## Emotional Design Opportunities

1. **Surprise & Delight:**
   - Random "free item" coupon in order for birthdays
   - Upgrade to next tier during visit (in-person celebration)
   - Handwritten thank you note for first-time customers

2. **Reduce Anxiety:**
   - Clear price breakdowns (no hidden fees)
   - Real-time order status (KDS visible to customers via tracking page)
   - Transparent loyalty expiry dates

3. **Build Community:**
   - Customer of the month spotlight
   - Referral leaderboard
   - Event invite for Platinum members

## Accessibility Considerations

- All touchpoints must support screen readers (ARIA labels)
- Color contrast meets WCAG AA (Bazi palette already compliant)
- Keyboard navigation for admin/KDS
- SMS notifications for customers without smartphones
