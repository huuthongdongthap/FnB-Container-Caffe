| **No Google Maps embed** | LOW | Add embedded map / directions link in contact area |

| **No loyalty signup CTA on landing** | MEDIUM | Landing should have "Dang ky loyalty nhan 50k" form |

## 11.2 Friction Points & Optimization

| Step | Friction | Fix | Impact |
|------|----------|-----|--------|
| **QR Scan** | Khach khong biet quet QR o dau | Menu bang + decal ban ro rang + nhan vien chi dan | Giam hoi "quet o dau?" |
| **Menu Load** | Menudang choi (loading state) | Optimize API response + cache menu in KV | <2s TTFP |
| **Checkout** | Khach chua quen thanh toan online | Add instruction popup on first order + COD option | Tang conversion rate |
| **KDS Delay** | Bar qua tai, order tre | KDS queue prioritization + prep timer alert | Giam wait time |
| **Loyalty Signup** | Khach nhap SDT bi lag | Pre-validate + auto-dial code | Tang signup rate |
| **Receipt/Ack** | Khach khong biet order da gui | Screen confirmation + push notification + sound | Giam confusion |

# Step 12 — GTM Experiments

## 12.1 Experiment Framework

Each experiment follows: Hypothesis -> Action -> Metric -> Verdict (2-week cycles)

## 12.2 Experiment 1: "Happy Hour Flash"

| Element | Detail |
|---------|--------|
| **Hypothesis** | Gioi tre Sa Dec nhay cam voi FOMO. Flash sale limited-time (2h) se tao luot order cao dot bien. |
| **Action** | Chon 1 signature drink moi tuan, sale 50% trong 14:00-16:00 Thu 5. Quang cao tren TikTok 1 ngay truoc. |
| **Success Metric** | Orders in window x2 baseline; new customer signups via QR |
| **Duration** | 4 weeks (4 iterations) |
| **Cost** | ~1.5M/thang (margin reduction, offset by volume) |
| **Track** | Number of orders per window, new phone signups, repeat rate |

## 12.3 Experiment 2: "Referral Battle"

| Element | Detail |
|--------|--------|
| **Hypothesis** | Gamification + leaderboard se thuc day referral nhieu hon passive "gioi thieu ban." |
| **Action** | Month-long contest: top 3 referrers win (1st: VIP dinner + 500K voucher, 2nd: 300K, 3rd: 150K). Real-time leaderboard on admin dashboard. |
| **Success Metric** | Referral count x3 vs baseline; new customer via referral |
| **Duration** | 30 days |
| **Cost** | 1M (prizes) |
| **Track** | Referral count, conversion rate of referred customers, cost per acquisition (CPA) |

## 12.4 Experiment 3: "Subscription Lock"

| Element | Detail |
|--------|--------|
| **Hypothesis** | Dan van phong chi tieu deu dand se subscribe neu thay "tiet kiem ro rang." Giam retention churn 20%. |
| **Action** | Launch subscription tiers: 10 coffee/month prepaid 250K (vs 350K retail) + Loyalty points boost. Auto-renew via PayOS. |
| **Success Metric** | Subscriber count, monthly churn rate, average ticket of subscribers vs non |
| **Duration** | 8 weeks (2-month commitment) |
| **Cost** | Margin reduction (20% discount) |
| **Track** | Subscription activation rate, auto-renewal %, LTV comparison |

## 12.5 Experiment 4: "Event Stickiness"

| Element | Detail |
|--------|--------|
| **Hypothesis** | Su kien dinh ky (Nocturnal Session: jazz/Sat night, Workshop: coffee cuoi tuan) se tao loyalty cao va differentiate vs competitors. |
| **Action** | 2 events/thang: Week 2: Acoustic Night (jazz, 19:00-21:00); Week 4: Coffee Workshop (Sunday 15:00-17:00). |
| **Success Metric** | Event attendance, post-event revisit within 7 days (prove stickiness), UGC generated |
| **Duration** | 6 weeks (3 event cycles) |
| **Cost** | ~3M/thang (musician/supplies + marketing) |
| **Track** | Attendance count, revisits within 7 days, total event UGC posts, referral signups at events |

## 12.6 Experiment 5: "Loyalty Push Notification"

| Element | Detail |
|--------|--------|
| **Hypothesis** | Push notification via Zalo ZNS/SMS khi loyalty gan het han se kich hoat revisit. |
| **Action** | Trigger: "Ban con 50 points sap het han. Den AURA trong 48h de nhan doi diem." A/B test: SMS vs Zalo ZNS. |
| **Success Metric** | Revisit rate within 48h of notification, notification CTR |
| **Duration** | 4 weeks |
| **Cost** | ~200K/thang (SMS/ZNS costs) |
| **Track** | Open rate (Zalo), revisit rate, average spend on revisit order |
