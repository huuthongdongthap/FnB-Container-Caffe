# Menu drink imagery

## Goal
Create six product photographs for existing AURA menu drinks using the supplied images as lighting and material references. Remove all Viva Star branding, including marks printed on cups. Keep originals untouched.

## Design
Warm natural window light, pale stone and wood, subtle foliage, realistic drink textures. One drink centered per frame, full vessel visible with generous crop safety for landscape menu cards. No text, logos, badges, prices, or watermarks baked into photographs.

## Acceptance
- Six distinct photographs: black iced coffee, Vietnamese milk coffee, salted coffee, hot matcha latte, strawberry smoothie, avocado smoothie.
- Review every output for residual branding and correct beverage identity.
- Save originals and optimized WebP assets in the project; provide a responsive visual review page.
- Connect exact matching menu entries to the new assets without changing prices, product identity, or ordering behavior.
- Validate image decoding, paths, and relevant existing menu checks. No deployment.

## Workflow
Sequential specification then implementation, following recipes/ui/design-component.json. Recipe output documents are placed in this plan directory to respect repository documentation rules. The project has existing unrelated work; preserve it.
