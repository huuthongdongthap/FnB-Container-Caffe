## Scope

### Delivered
- OAuth2 client credentials auth with in-memory token caching + expiry buffer
- Contact CRUD: single upsert + batch upsert (50/batch)
- Segment membership: tier (Bronze/Silver/Gold/Platinum), recency (active/at-risk/inactive), birthday-this-month
- Campaign enrollment: win-back (31-day threshold), birthday (month match), promo (admin-triggered, tier/recency filter)
- Email via Resend: Vietnamese UTF-8, timeout, graceful degradation
- SMS via SpeedSMS: phone normalization (+84), brandname type, Vietnamese content
- Campaign enrollment tracking D1 table for dedup + audit
- Delta sync via KV timestamp cursor
- Exponential backoff retry (5xx + network errors)
- FastCGI body-token fallback for stripped Authorization headers
- Error isolation: batch failure does not block remaining batches

### Out of Scope (Carried Forward)
- Mautic campaign creation in UI (must be pre-configured in Mautic)
- Zalo ZNS integration (already existed in `zalo.js`, reused)
- ERPNext integration (stub in cron.js, deferred)
- Admin API endpoint for manual promo triggers (can be added later via `triggerPromoCampaign`)
